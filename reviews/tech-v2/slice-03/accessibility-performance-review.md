# Accessibility and performance review

PASS

The context selector uses tablist, tab, and tabpanel semantics with roving keyboard focus. Datum controls expose the current step. Mobile construction-state controls are grouped and expose their mutually exclusive selection with `aria-pressed`; the fresh browser evidence records the correct pressed state after expanded, bridge, and controlled selections.

Reduced motion resolves to the final construction state with transitions disabled. The current capture reports no console errors, broken images, document overflow, or running construction animations, and `apps/engineering` remains unchanged.
