# Milestone B — Core Interactive Landing

Authoritative cadence: `a-modul-fast-execution-override.md`. Product and factual requirements remain governed by the original A-Modul master specification and the approved source registry.

## Required implementation

- object-composition configurator with type, capacity, region, functional zones, missing inputs, next step, and local context handoff; never output an invented module count;
- complete project-risk chain from source data through launch, ending in one project contour / one schedule / one accountable result;
- regional personalization and a code-driven interactive SVG logistics map covering road, rail, sea, river, winter road, and mixed delivery without fake price, distance, or duration;
- similar-project finder with region, industry, type, capacity, climate, and delivery filters, using only verified case facts and explicitly naming differences when no exact analogue exists;
- finite BIM-to-object sequence from site plan through operational object, using generated plates plus code-driven overlays and a complete reduced-motion conclusion;
- generated factory visualization, interactive production sequence, and approved current production indicators with a project-specific caveat;
- transparent price-completeness matrix comparing a module-only number with the full launch scope; no universal per-m² price;
- dominant Kamchatka case with exact verified facts, generated visualization disclosure, and no documentary-photography implication;
- locked seismic evidence phrase and support, scoped to the published Kamchatka evidence.

## Deterministic gate

- typecheck, lint, test, and production build pass;
- route/root/canonical remain correct;
- zero console/page/request errors and broken images after every lazy visual is hydrated;
- no horizontal overflow at 320, 390, 768, or 1440;
- H1, primary CTA, and exact one-working-day qualification remain in the initial viewport;
- all nine Milestone B sections render, all controls are labeled, visible targets meet 44×44, and every image has intrinsic dimensions;
- configurator state, all risk/factory controls, logistics route, exact/no-match finder behavior, full BIM autoplay, stable final state, and reduced-motion conclusions are exercised in a real browser;
- current desktop, tablet, mobile, intermediate, motion, diff, trace, and test evidence exists; no video.

## Review gate

1. Visual + Motion Reviewer;
2. Conversion + Engineering/Factual Reviewer;
3. Accessibility + Performance Reviewer.

Proceed on `PASS` or `CONDITIONAL PASS` only when every current report contains zero P0/P1. Any P2/P3 finding is recorded in `reviews/a-modul-v2/POLISH-BACKLOG.md`.
