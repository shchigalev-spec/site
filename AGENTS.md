# Repository rules

- `apps/tech` and `apps/engineering` are independent products. Never import runtime UI, CSS, components, assets, or design tokens across them.
- Shared facts and analytics names live only in `docs/`; there is no shared runtime UI package.
- Do not use or reference the legacy root Next.js source when building either SvelteKit app.
- Never invent prices, customer reviews, addresses, building complexes, system specifications, durations, legal guarantees, or certificates.
- Case imagery is illustrative and must never be presented as documentary customer photography.
- Use Geologica, Onest, and IBM Plex Mono. Inter is prohibited.
- Every major CTA leads to diagnosis.
- Use `apply_patch` for source edits and preserve parallel work.
