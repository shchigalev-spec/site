# Russia map asset and licence

The interactive logistics section uses a local copy of **Map of federal subjects of Russian Federation.svg** from Wikimedia Commons:

- source page: https://commons.wikimedia.org/wiki/File:Map_of_federal_subjects_of_Russian_Federation.svg
- original file: https://upload.wikimedia.org/wikipedia/commons/5/56/Map_of_federal_subjects_of_Russian_Federation.svg
- local file: `apps/a-modul/static/data/russia-federal-subjects.svg`
- authors credited on the source page: CrazyPhunk, Fremantleboy, Hardscarf and Chumwa
- licence: Creative Commons Attribution-ShareAlike 3.0
- local use: the SVG is displayed in monochrome through CSS and receives separate HTML/SVG planning overlays; the underlying subject boundaries are not removed.

The map is used for broad region recognition and preliminary interface selection. It is not a legal, surveying, routing or political-boundary statement.
