# Передача проекта в GPT Pro

Этот архив — полный исходный проект сайта «Лаборатория тишины». Он подготовлен
для продолжения работы в другом GPT-чате. Служебные и восстанавливаемые папки
(`node_modules`, `.git`, `.next`, `.vinext`, `.wrangler`, `dist`, `output`) из
архива исключены.

## Сообщение, которое нужно отправить вместе с архивом

> В архиве находится рабочая версия сайта «Лаборатория тишины» и исходный
> мастер-промпт `silent-lab-codex-master-prompt.md`. Сначала изучи проект и
> мастер-промпт, затем продолжай работу поверх текущей реализации. Не начинай
> сайт заново и не удаляй рабочую функциональность. Сохрани маршруты, SEO,
> диагностический квиз, серверный API заявки, интеграцию Bitrix, аналитику и
> адаптивность. Если предлагаешь новый визуал, внедряй его в существующую
> архитектуру. Не выдумывай неподтверждённые факты: список таких данных находится
> в `docs/CONTENT-TODO.md`. Перед выдачей результата запусти `npm run lint` и
> `npm test`, затем перечисли изменённые файлы и покажи результат.

Если нужна только новая Pro-версия дизайна, добавьте к сообщению:

> Основная задача — улучшить визуальный уровень и конверсионную подачу, не ломая
> текущую логику и структуру проекта.

## Текущее состояние

- React 19 + Vinext + React Server Components.
- Русскоязычный многостраничный сайт услуг шумоизоляции.
- Реализованы главная, страницы услуг, диагностика, кейсы, privacy, thank-you,
  sitemap и robots.
- Работает пятишаговый диагностический квиз с сохранением состояния, файлами,
  валидацией и обработкой кнопки «Назад».
- API заявки расположен в `app/api/lead/route.ts`.
- Bitrix-адаптер расположен в `lib/server/crm.ts`; секреты не попадают в клиент.
- События Метрики и сохранение UTM реализованы без передачи персональных данных.
- Неподтверждённые бизнес-данные перечислены в `docs/CONTENT-TODO.md`.
- Последняя проверенная версия проходила сборку, линтер и тесты.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run lint
npm test
```

Переменные окружения описаны в `.env.example` и `README.md`.

## Важные файлы

- `silent-lab-codex-master-prompt.md` — исходное подробное задание.
- `README.md` — запуск и конфигурация.
- `app/` — маршруты и API.
- `components/` — интерфейс и диагностический квиз.
- `lib/content/` — централизованный контент.
- `lib/server/crm.ts` — серверная интеграция CRM.
- `docs/CONTENT-TODO.md` — факты, которые нужно получить у владельца бизнеса.
- `docs/SEO-MAP.md` — карта SEO-страниц.
- `docs/METRICA-EVENTS.md` — события аналитики.

## Переменные для продакшена

- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_YANDEX_METRICA_ID`
- `BITRIX_WEBHOOK_URL`
- `BITRIX_ENTITY_TYPE`
- `BITRIX_FIELD_MAP_JSON`

Не публикуйте webhook Bitrix в клиентском коде или переписке.
